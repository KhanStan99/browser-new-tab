Settings & backup

Everything you add is stored only in this browser, never in the HTML file.

 

 

Clearing your browser’s cookies and site data erases this page’s storage. Download a backup now and then if the notes matter.

Edge, Chrome and Firefox can each export their bookmarks to an HTML file. Folders become groups, a nested folder becomes “Parent / Child”, and any icons stored inside the file are used directly — so those bookmarks need no favicon service and work offline.

How to set this page as your home page

This page’s address — paste it into your browser’s home page setting:

  • Chrome / Edge — Settings → Appearance → turn on Show home button → choose the custom address and paste it.
  • Firefox — Settings → Home → Homepage and new windows → Custom URLs → paste it.
  • Safari — Settings → General → Homepage → paste it.

The new tab page cannot be changed to a local file without a browser extension — the home button can.
